# Бот Тёплого места для организаторов

Что нужно один раз:
1. Скопировать `.env.example` в `.env` и вписать токен бота (`BOT_TOKEN`). Файл `.env` никому не отправлять.
2. Положить рядом с `bot.py` фото для приветствия под именем `welcome.jpg` (без него бот шлёт только текст).
3. Менеджер (@event_teploemesto) открывает бота, нажимает /start, затем отправляет команду /id. Бот пришлёт число. Его нужно вписать в `.env` как `MANAGER_CHAT_ID`. Без этого сообщения про повторное проведение не дойдут до менеджера.
4. Премиум-эмодзи. В тексте «Помощь» уже подставлен номер вашего эмодзи (5352589626701818843). Для логотипа в приветствии нужен номер его премиум-эмодзи: возьмите его из текста приветствия в прежнем боте (в конструкторе он виден в записи вида `<tg-emoji emoji-id="…">`) и впишите в `.env` как `LOGO_EMOJI_ID`. Пока он не вписан, вместо логотипа показывается 🔸. Премиум-эмодзи бот может отправлять не всегда: если Telegram их не принимает, вместо них показываются обычные.
5. Установить и запустить:

```
pip install -r requirements.txt
python bot.py
```

Бот должен быть запущен всё время (на сервере или на облачном хостинге). Если запускать на своём компьютере, он работает только пока компьютер включён.

Если у бота сейчас включён вебхук или он подключён к конструктору, то одновременно с этим скриптом работать нельзя. Сначала отключите бота в конструкторе, иначе Telegram ответит ошибкой Conflict.
